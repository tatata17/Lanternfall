# Lanternfall

闇に包まれた競技場で、ランタンの灯りを守りながら影たちを払い続けるブラウザゲームです。make.fun のゲーム制作コンペ「best-game-01」への提出作品です。

![プレイ画面](screenshots/%E3%83%97%E3%83%AC%E3%82%A4%E7%94%BB%E9%9D%A2.jpg)

## ゲームについて

- ランタンの燃料は時間とともに減り続け、光の輪が少しずつ狭くなっていきます。真っ暗闇そのものでは死にませんが、視界を失うと影に囲まれます
- 倒した敵が落とす「残り火」を拾って燃料を補給します。残り火は3サイズ(小・中・大)で、大きいものほど遠くから引き寄せられます
- ウェーブを乗り切るごとに、3つの強化から1つを選んでビルドを育てていきます(レベル制・上限あり)
- 10ウェーブごとにボス戦(全8種)。時間制のアイテム、ストック式の回復薬とボム、連続ヒットのボーナスなど、生き残るほど要素が増えていきます

## 遊び方

リポジトリを静的サーバーで配信し、`game/index.html` を開いてください(ESモジュールを使っているため `file://` では動きません)。

```
python3 -m http.server 8000
# → http://localhost:8000/game/
```

GitHub Pages を有効にすれば、そのままブラウザで遊べるようになります。

## 操作

- 移動: WASD / 矢印キー
- 照準: マウス(タイトル画面で「移動方向に撃つ」方式にも切替可。Vキーでも切替)
- 射撃: クリック長押し / スペース
- 回復薬: H、ボム: B(拾ってストックした分だけ使えます)
- ポーズ: P / Esc、フルスクリーン: F
- スマートフォンではツインスティック操作に対応。縦持ちでは専用パッドと縦長フィールドになります

## 構成

- `main.ts` / `vendor/` — make.fun 提出用のキット一式
